# 项目简介

**Card Ripper（球星卡模拟拆卡器）** 是一个纯前端的足球球星卡模拟拆卡网页。
用模拟余额购买卡盒、逐包撕开、逐张翻卡，体验真实的拆卡乐趣；拆到的卡自动存入
收藏册（浏览器本地保存）。无后端、无真实付费，可直接通过链接分享给朋友。

- 线上地址：<https://xxr0000.github.io/card-ripper/>
- 仓库：<https://github.com/xxr0000/card-ripper>
- 技术栈：Vite + React 19 + TypeScript，无任何运行时依赖后端

## 核心玩法

1. **卡店**：陈列 4 个系列的卡盒（价格、盒规、保底说明与真实产品一致）
2. **模拟钱包**：初始 ¥20,000，可无限充值，购盒扣款
3. **拆盒**：整盒到手 → 选包撕开 → 点击翻卡，稀有卡触发全屏特效，命中压轴出现
4. **收藏册**：自动收录，可按系列 / 签名 / 物料 / 带编 / 1-of-1 筛选，点卡放大

## 关键设计

- **数据驱动**：系列的所有内容（平行种类、编号档位、爆率权重、保底）都在
  `data/series.ts` 中声明式配置，新增系列不需要改引擎
- **拆卡引擎**（`engine/rip.ts`）：先铺满普通卡位 → 按盒槽位放入平行、插卡与命中 →
  应用官方逐包赔率 → 包内按稀有度排序制造翻卡节奏
- **卡面绘制**（`CardFace.tsx/css`）：显式实图可用时叠加展示，缺图自动回退到
  CSS/SVG 致敬设计；平行效果、编号、签字和物料层保持独立
- **正式卡目**：四系列均使用独立 checklist；基础、插卡、签名、物料与签物名单分离。
  厂家未公布的无编平行和命中类型拆分保留为显式估算项
- **持久化**：余额与收藏存 localStorage；收藏使用兼容旧版的 v2 紧凑格式，
  收藏册每批渲染 48 张并可继续加载

## 开发与调试

```bash
npm install
npm run dev                    # 本地开发 http://localhost:5173
npm run build                  # 生产构建 + 体积门禁
npx tsx scripts/simulate.ts    # 模拟 10000 盒×4 系列，校验盒规/编号/赔率
```

- 访问 `/?preview` 可一次性预览所有系列全部平行的卡面样式
- 部署：当前使用 Sites + Cloudflare Worker 静态资源构建；根路径托管设置 `VITE_BASE_PATH=/`，同时保留 GitHub Pages 子路径和私有 Vercel 备选配置
