# 项目简介

**Card Ripper（球星卡模拟拆卡器）** 是一个纯前端的足球球星卡模拟拆卡网页。
用模拟余额购买卡盒、逐包撕开、逐张翻卡，体验真实的拆卡乐趣；拆到的卡自动存入
收藏册（浏览器本地保存）。无后端、无真实付费，可直接通过链接分享给朋友。

- 线上地址：<https://xxr0000.github.io/card-ripper/>
- 仓库：<https://github.com/xxr0000/card-ripper>
- 技术栈：Vite + React 19 + TypeScript，无任何运行时依赖后端

## 核心玩法

1. **卡店**：陈列 4 个系列的卡盒（价格、盒规、保底说明与真实产品一致）
2. **模拟钱包**：初始 ¥20,000，可无限充值，购盒扣款
3. **拆盒**：整盒到手 → 选包撕开 → 点击翻卡，稀有卡触发全屏特效，命中压轴出现
4. **收藏册**：自动收录，可按系列 / 签名 / 物料 / 带编 / 1-of-1 筛选，点卡放大

## 收录系列（2024-25）

| 系列 | 盒规 | 保底 | 特色 |
| --- | --- | --- | --- |
| Panini Prizm 英超 | 12包×12张 | 2 签名 | 银折/彩折体系、Color Blast 案例卡 |
| Panini Select 西甲 | 12包×5张 | 1签+1物料 | Terrace/Field/Stadium 分层底卡、扎染 |
| Panini Obsidian 黑曜石 | 1包×7张 | 2签+2物料 | 全球卡池（含梅西、C罗），全员带编 |
| Topps Chrome 欧冠 | 24包×4张 | 1 签名 | Refractor 折射体系、SuperFractor |

爆率按真实产品手感设定（银折约 1:11 卡、金折 /10 约 1:1100、1/1 约 1:6500），
签名卡中大牌按"短印"逻辑更难抽出。

```
├── vite.config.ts              # Vite 配置（GitHub Pages 子路径 base）
├── scripts/
│   └── simulate.ts             # 批量模拟拆盒脚本，验证保底与爆率分布
└── src/
    ├── main.tsx                # React 挂载入口
    ├── App.tsx                 # 顶层状态（页面切换/钱包/收藏）+ ?preview 卡面预览

    ├── index.css               # 基础样式与暗色主题背景
    ├── types.ts                # 全部类型定义（球员/平行/系列/卡片）
    ├── store.ts                # localStorage 读写（余额、收藏）
    ├── data/
    │   ├── players.ts          # 球员卡池（约 100 名，含联赛/球队/国籍/梯度/新秀）+ 球队配色
    │   └── series.ts           # 4 个系列配置：盒规、价格、平行池与权重、签名/物料池、保底
    ├── engine/

    └── components/

        ├── CardFace.css        # 各系列主题、平行卡特效（折射/扎染/电光等 CSS 动画）
        ├── Shop.tsx            # 卡店页
        ├── RipView.tsx         # 拆盒流程页（选包 → 翻卡 → 总结）
        └── Collection.tsx      # 收藏册页（统计、筛选、大图弹窗）
```

## 关键设计

- **数据驱动**：系列的所有内容（平行种类、编号档位、爆率权重、保底）都在
  `data/series.ts` 中声明式配置，新增系列不需要改引擎
- **拆卡引擎**（`engine/rip.ts`）：先铺满普通卡位 → 按权重抽平行与编号 →
  保底命中随机分配到不同包并替换末位卡 → 包内按稀有度排序制造翻卡节奏
- **卡面绘制**（`CardFace.tsx/css`）：目前为纯代码绘制的"致敬设计"，
  用 CSS 变量注入球队配色，平行样式通过类名叠加
- **当前近似项**：球员名单为手挑的约 100 人精选池，爆率为参考真实手感的
  近似权重；对齐官方 checklist 与真实赔率的方案见《真实化升级计划》
- **持久化**：余额与收藏存 localStorage，每个浏览器独立存档

## 开发与调试

```bash
npm install
npm run dev                    # 本地开发 http://localhost:5173
npm run build                  # 生产构建
npx tsx scripts/simulate.ts    # 模拟 2000 盒×4 系列，校验保底/编号/爆率
```

- 访问 `/?preview` 可一次性预览所有系列全部平行的卡面样式
- 部署：构建产物推送 `gh-pages` 分支（`npx gh-pages -d dist`），GitHub Pages 托管
