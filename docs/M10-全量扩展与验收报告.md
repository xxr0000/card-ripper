## 质量门禁

- 每条正式素材都保留球员姓名、来源页、获取日期、原图尺寸和验证状态。
- 每位球员生成 500×700 缩略图和 1000×1400 大图；小卡不会请求大图。
- 自动审计逐个读取 1,808 个文件，检查 WebP 格式、尺寸、单图上限、清单键、HTTPS 来源页、
  缺失文件、孤儿文件与跨球员 SHA-256 重复内容。
- 审计发现并修正孙兴慜同人异名重复；最终重复内容、身份待确认和清单错位均为 0。
- 对排序后跨卡池抽样的大图进行视觉复核，人物主体、清晰度和纵向裁切均符合卡面使用要求。

## 存储决策

当前球员媒体为 109.46MiB、1,808 个文件，单张大图不超过 300KiB。规模仍可由 Git 和当前
静态资源构建承载，且无需引入对象存储凭据、跨域或运行时外部依赖，因此 M10 继续随仓库保存。
构建门禁从试点的 15MiB 调整为全量 120MiB；若后续新增系列使该门禁不足，再迁移到对象存储。

## 回归与发布边界

- 桌面本地预览验证真实图片成功加载 1000px 大图，拆包、翻卡、音效开关、自动连翻与大卡暂停正常，控制台无警告或错误。
- 390×844 移动视口无横向溢出，按钮均在视口内；卡面只请求 500px 缩略图，不会误下载 1000px 大图。
- 键盘操作、减少动态效果、静音与播放失败降级由组件逻辑和自动测试覆盖。
- 完整检查包括 lint、单元/流程测试、TypeScript、生产构建、10,000 盒概率模拟、媒体审计和
  三段式资源体积门禁。
- 本阶段不执行线上发布。用户确认本地/受控预览中的卡图和音效方向后，再单独发布。
