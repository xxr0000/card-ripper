# M9 真实音效报告

日期：2026-08-19

## 结果

- 使用 11 个本地 MP3 替换 Web Audio 振荡器，总体积约 960KB，低于 2MB 门禁。
- 拆包分为拖动褶皱、达到阈值撕裂、完全打开松开三段，并与手势进度同步。
- 每次翻卡从 4 个纸张/卡片采样中随机选择，并轻微改变播放速率和音量。
- 稀有提示始终叠加在翻卡声之后：编号卡、签名/物料、案例卡、1/1 使用不同录音。
- 音量和静音沿用用户设置；浏览器禁止播放、缺少音频能力或文件加载失败时静默降级，不阻塞拆包。

## 素材与来源

所有候选均来自 Mixkit 免费音效库，下载后保存在 `public/audio/`，运行时不访问第三方地址。素材使用遵循 [Mixkit Free License](https://mixkit.co/license/#sfxFree)。

## 自动验收

- 11 个清单路径均指向本地 `audio/` 目录，翻卡随机边界与四档稀有映射有单元测试。
- 构建门禁将音频单独统计，限制为 2MB，避免球员媒体和音频掩盖应用主体积。
- `lint`、测试、TypeScript 构建和生产构建均纳入 M9 提交前检查。

## 人工复核建议

最终线上发布仍属于 M10 之后的独立动作。受控预览时重点试听连续翻卡是否舒适、移动设备首次触控能否发声，以及四档提示音是否容易区分。
