# M8 高清球员素材试点报告

> 完成日期：2026-08-19

## 结果

- 已为 100 名核心球员建立经过姓名匹配核对的摄影图素材记录。
- 每位球员有 `500×700` 缩略图与 `1000×1400` 放大图两份 WebP；真卡图仍优先于球员摄影图，加载失败时继续回退绘制卡面。
- `src/data/player-media.generated.ts` 记录来源页、获取日期、原始尺寸、焦点坐标和核对状态；源图只作为本地处理输入，不提交仓库。

## 性能门禁

- 球员媒体采用 `<picture>`：大卡仅在宽度达到 480px 时请求放大图，小卡只请求缩略图。
- 构建门禁拆分为 5MB 应用资源上限与 15MB 延迟加载试点媒体上限，避免首屏下载全部摄影图。
- 当前 100 人共 200 份 WebP，媒体目录约 13MB；单张大图均不超过 300KB。

## 素材来源与复核

- 批量照片来自 TheSportsDB 公开球员资料；Rodri 使用 Manchester City 官方球员页补齐。
- 下载脚本仅接受规范化姓名与候选资料姓名完全匹配的结果；名称不一致的少数球员使用显式别名，来源页仍逐张保留。
- M10 将按相同规则扩展其余卡池，并在全量媒体规模下评估对象存储迁移。
