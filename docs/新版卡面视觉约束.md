# Card Ripper 新版卡面视觉约束

> 状态：已通过方向确认，作为 M11 全量卡面改版的视觉基线
> 确认日期：2026-08-19
> 参考入口：`/?design-preview`
> 适用范围：Prizm EPL、Select LaLiga、Obsidian、Topps Chrome 的底卡、插卡、编号卡、签名卡、物料卡和签物卡

## 1. 目标与边界

新版卡面统一采用“等级边框 + 横向照片窗 + 独立信息区”的结构。球员照片只出现在照片窗内，
姓名、球队、签名、物料、平行名称和编号全部位于照片窗外。保留折射与动态光效，但光效不得破坏
照片主体或文字可读性。

本次改版只改变卡面视觉与图片素材形态，不改变：

- 卡池、checklist、抽取概率、盒规和编号生成逻辑；
- 余额、收藏存档和旧存档兼容逻辑；
- 拆包、翻卡、自动连翻、音效、震动与收藏筛选功能；
- 卡面全英文、网页外围界面中文的既有规则。

## 2. 禁止项

以下设计不得进入正式卡面：

- 球员图片铺满整张卡；
- 在图片上覆盖大面积斜线、色块、渐变文字底或强烈折射层；
- 姓名、签名、物料窗、平行名称或编号直接压在球员照片上；
- 为了填满照片窗而使用明显失真的拉伸，或把近景头像强行放大裁切；
- 人脸、头顶、下巴或主要动作部位被照片窗边框遮挡；
- 照片窗出现黑边、空白边或与卡框无关的填充色；
- 签名、认证小字或编号因旋转、溢出裁切、文本省略而显示不完整；
- 明显水印、付费预览遮罩、错人、身份不确定或清晰度不足的图片。

## 3. 固定版式

### 3.1 卡体

- 卡片比例固定为 `5:7`，沿用现有 `sm`、`md`、`lg` 三档尺寸。
- 外边框、内照片框和信息框使用同一等级色系，但明暗层次必须可区分。
- 卡片圆角、阴影和交互倾斜沿用现有体验；边框不得因动画改变布局尺寸。

### 3.2 顶部标识

- 品牌与年份位于照片窗上方，左右对齐。
- 文字保持英文大写或数字，字号低于球员姓名，但在 `sm` 尺寸仍可辨认。
- 顶部标识不得进入照片窗，也不得被折射高光覆盖到无法读取。

### 3.3 横向照片窗

- 照片窗应为明显横向构图，目标显示比例为 `1.45:1` 至 `1.60:1`。
- 参考位置：距卡片顶部约 `11%`，左右各约 `6%`，高度约为卡片的 `43%`。
- 照片与内框之间保留稳定的暗色压边，不允许图片越过内框。
- 图片使用 `object-fit: cover` 填满照片窗，但必须先通过素材适配检查并设置人工焦点；
  不能用 `cover` 掩盖素材本身比例不合适的问题。
- 折射层位于卡框和底板，不覆盖照片；照片只允许轻微统一饱和度与对比度。

### 3.4 信息区

- 信息区位于照片窗下方，与照片窗至少保留一个可见间隙。
- 普通卡信息区参考高度为卡片的 `31%`；签名、物料和签物卡可扩展到约 `38%`。
- 球员姓名为信息区第一视觉层级，球队、国家和位置为第二层级。
- 平行名称左对齐，编号右对齐；编号使用等宽字体并保持完整的 `NN/NNN` 形式。
- `md` 和 `lg` 尺寸不得省略球员姓名；长姓名应优先缩小字号，再考虑两行显示。

## 4. 等级边框体系

边框等级只由卡片稀有度决定，卡种只影响下方信息区，不改变稀有度判断。

| 稀有度 | 主边框 | 辅助表现 | 动效强度 |
| --- | --- | --- | --- |
| Base | 石墨灰 / 暗银 | 低对比内框，无持续辉光 | 0 |
| Shine | 银白 / 冷灰 | 轻微虹彩折射 | 1 |
| Numbered | 蓝色 | 蓝色内框与编号强调 | 2 |
| Low-numbered | 金色 | 暖金内框与柔和辉光 | 2–3 |
| Super | 金色 / 系列高级色 | 更强折射，但不覆盖照片和文字 | 3 |
| One-of-one | 黑金 | 黑色底板、金色双层边框和最高级辉光 | 4 |

约束：

- 不再为每种平行卡在整张卡上增加大面积专属斜线颜色层。
- 系列主题可改变底板纹理和细节色，但不能覆盖上述等级识别。
- 同一稀有度在四个系列中应一眼可辨为同一等级，同时保留系列细节差异。
- `prefers-reduced-motion` 或关闭动效时，静态边框仍必须表达完整等级。

## 5. 图片素材约束

### 5.1 构图

优先级从高到低：

1. 横向比赛动作照，人物全身或大半身，背景为球场或虚化看台；
2. 横向训练或庆祝照，人物周围有足够安全空间；
3. 可安全裁成横图的高分辨率半身照；
4. 无可靠照片时使用新版边框内的绘制回退，不使用错人或低质量素材凑覆盖率。

每张图片必须满足：

- 原图建议不低于 `1200×675`；最低不得低于最终大图输出尺寸。
- 人脸完整且清晰，头顶和下巴距最终裁切边缘保留至少画面高度的 `8%`。
- 人物视觉中心位于画面中间约 `60%` 的安全区；动作方向前方应保留空间。
- 横向裁切后不得只剩脸部特写，也不得切断主要动作所需的手臂、腿或足球。
- 球衣、年代和俱乐部可以与卡片系列不同，但人物身份必须确定。

### 5.2 素材处理

- 新增横向小图与大图两档，建议输出为 `720×480` 和 `1200×800` WebP。
- 每位球员记录来源页、获取日期、原始尺寸、焦点位置、适配状态和人工复核状态。
- 焦点至少支持水平位置；复杂构图应同时支持垂直位置和安全区备注。
- 现有竖版球员图不能机械转换。先检查原始来源图：原图适合横裁时重新生成，
  不适合时重新检索横向图片。
- 正式卡面优先使用横向球员摄影图。现有完整卡面扫描图保留元数据，但不得作为新版照片窗中的“卡中卡”。

## 6. 签名与物料

### 6.1 签名卡

- 签名必须位于照片窗外的浅色认证区，使用深蓝色墨迹，形成清晰对比。
- 认证区固定包含一行 `CERTIFIED AUTOGRAPH`，该行不得被签名覆盖或裁掉。
- 签名为认证区第一视觉层级，字号应明显大于认证小字和球员介绍。
- 签名不使用会导致越界的明显旋转；所有字形必须完整留在认证区内。
- 长签名允许按可用宽度缩放，但不得使用省略号或隐藏溢出。

### 6.2 物料卡

- 物料窗位于独立认证区内，不覆盖照片。
- 保留 `PLAYER-WORN PATCH` 或 `MATCH-WORN JERSEY` 等说明文字。
- Patch 与 Jersey 使用不同纹理；物料窗边框与卡片等级边框保持协调。

### 6.3 签物卡

- 物料窗在左，签名区在右；签名区宽度优先于装饰留白。
- 认证小字、物料说明、签名和平行名称必须同时完整可见。
- 空间不足时依次缩小球员介绍、物料说明和签名字号，禁止裁切内容。

## 7. 响应式与可访问性

- `lg`：全部文字、认证信息和图片细节完整显示。
- `md`：作为正式验收基准，所有必要信息必须完整且清晰。
- `sm`：允许缩短次要介绍，但球员姓名、签名、物料类型、平行名称和编号不得消失。
- 图片必须有包含球员与系列名称的替代文本。
- 动效关闭时不得影响布局和等级识别；图片加载失败时显示同版式的绘制回退。
- 卡片在收藏册、翻卡页、总结页和放大弹窗中不得发生文字或边框溢出。

## 8. 验收清单

每张进入正式版本的代表卡至少检查以下项目：

- [ ] 图片填满横向照片窗，无黑边和空白边。
- [ ] 人脸、头顶、下巴和主要动作没有被裁切或边框遮挡。
- [ ] 球员姓名完整，球队、国家和位置可读。
- [ ] 签名明显，认证小字完整，签名不越界。
- [ ] 物料窗、物料说明和平行名称互不遮挡。
- [ ] 编号完整、位置稳定，1/1 能明确识别。
- [ ] 折射效果保留，但不覆盖照片和文字。
- [ ] `sm`、`md`、`lg` 三档无布局溢出。
- [ ] 动效关闭和图片加载失败时仍可用。
- [ ] 卡面仅使用英文，不改变外围中文界面。

## 9. 变更控制

- `/?design-preview` 保留为视觉基准页，正式组件变更必须先在该页覆盖代表组合。
- 修改边框等级、照片窗比例、签名区结构或素材规格时，应同步更新本文档。
- 未通过代表卡验收前，不批量替换全部素材；未通过全量回归前，不发布线上版本。
